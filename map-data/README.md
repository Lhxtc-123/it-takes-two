# Map data

This directory is populated by:

```powershell
npm run map:fetch
```

Boundary data comes from DataV GeoAtlas. It is used only for the private, non-commercial TravelAtlas prototype.

The application must always show:

> 非标准地图，仅供个人旅行记录

Do not treat these boundaries as standard maps for publication, navigation, surveying, or commercial use.
